# Retrieval / Recuperación
The target architecture combines Qdrant dense retrieval with PostgreSQL lexical retrieval.
La arquitectura objetivo combina recuperación densa en Qdrant y búsqueda léxica en PostgreSQL.
Scope and document permissions must be applied before retrieval in the future team deployment.
En el futuro despliegue de equipo, los permisos documentales se aplican antes de recuperar evidencia.
When generation is unavailable, return retrieved evidence with an explicit status.
Si la generación no está disponible, devolver evidencia recuperada con un estado explícito.
