# Extraction / Extracción
GLiNER2 is the proposed structured extraction component, separate from embedding and generation.
GLiNER2 es el componente propuesto de extracción estructurada, separado de embeddings y generación.
An ExtractionRun records fork commit, checkpoint hash, schema, thresholds and language settings.
ExtractionRun registra commit, hash del checkpoint, esquema, umbrales e idioma.
Hosted GLiNER2API is excluded from the disconnected profile; local AutoExtractor needs a complete checkpoint.
GLiNER2API alojada queda excluida del perfil desconectado; AutoExtractor local necesita un checkpoint completo.
